# نظام الاتصالات الإدارية

تطبيق عربي لإدارة المعاملات الصادرة والواردة، يعمل مباشرة من المتصفح ويمكن نشره عبر GitHub Pages.

## المزايا

- تسجيل المعاملات الصادرة والواردة.
- البحث برقم المعاملة والجهة والموضوع والتاريخ.
- تعديل السجلات وحذفها.
- واجهة عربية باتجاه من اليمين إلى اليسار.
- استخدام التاريخ الهجري.
- حفظ البيانات محليًا داخل المتصفح باستخدام IndexedDB.

## التشغيل محليًا

افتح ملف `index.html` باستخدام Chrome أو Edge.

## النشر عبر GitHub Pages

ارفع الملفات إلى مستودع GitHub، ثم فعّل GitHub Pages من إعدادات المستودع على الفرع `main` والمجلد الجذري `/ (root)`.

## ملاحظة مهمة عن البيانات

البيانات لا تُرفع إلى GitHub، وإنما تُحفظ داخل المتصفح على الجهاز المستخدم. لكل متصفح وجهاز ونسخة منشورة مساحة بيانات مستقلة.
